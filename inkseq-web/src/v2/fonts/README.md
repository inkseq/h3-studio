# Prototype font, served from the same origin

`inter-latin-v20.woff2` is the unmodified Latin variable font returned for the approved prototype's existing Google Fonts Inter 400/500/600/700/800 request. It is self-hosted so the static preview can retain its strict CSP and render the prototype typography without connecting to Google at runtime.

- Original source: `https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700;800&display=swap`

- SHA-256: `4ce3dc1af0117e2edfd9c8c5fb978251018f5f4d3ef88325796abfc3e680ef18`

No remote stylesheet or font request is made by this adapter. Chinese text continues using the existing system fallback.
