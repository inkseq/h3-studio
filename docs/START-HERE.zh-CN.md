# 明天回来先这样看

本轮把映序做成了共用账户、项目、素材、队列和下载 API 的工作室。界面和本地 CPU 流程可以操作；**公网还没上线，GPU保持关闭，当前视频生成是明确标记的 CPU 模拟**。真实模型效果请看既有 H3 样片，不能用这些模拟片判断。

## 五分钟走一遍

1. 打开 [映序工作室](http://localhost:8851)。左栏先显示 **我的故事**；选中故事后，左栏切换为该故事的菜单和章节。点顶部 **‹ 我的故事** 可返回列表选别的故事；**新建故事** 位于列表层，可填写名字并选择云端或仅此浏览器保存。未登录时点 **登录，查看云故事**，本机测试可输入 `supervan`。该免密码入口只在本机，正式站点采用密码登录。
2. 打开 **十故事验收 · 雨夜信箱**。沿顶部七个阶段查看故事、章节、人物与场景、镜头参考、审片和交付。左侧 **新增章节** 可以手动添加，章节里再加场景和镜头，不需要先让 AI 生成脚本。
3. 点 **无限画布**，检查同一作品的节点、连线和素材。再切回引导工作台，数据仍是同一份。画布使用 ReactFlow；ComfyUI 位于执行后端，不向普通用户开放任意插件运行。
4. 打开 **剪辑选段验收 · 雨夜信箱**，在“节奏与声音”看镜头入点、出点、音轨位置与音量。已经生成的章节成片可以播放和下载；没有拿视频播放截图代替实际编码结果。
5. 打开 **字幕烧录验收 · 独立模拟副本**，在“交付检查”展开已完成的粗剪。可播放、下载 MP4，手动字幕可另存 SRT。烧入画面与独立字幕文件是两个明确选项。

这些都是本轮单独建立的验收作品。更改云作品后点 **保存云版本**；如需保留当前验收版本，可以打开云项目面板，用 **复制当前作品到云端** 建立副本，再按提示同步素材。刷新后可继续上次云作品，本机未同步草稿会先让你选择，不自动覆盖。

## 已经落到代码的核心

- 一次创作和短剧共用图片、视频、音频、首尾帧、锚点、参数和项目 API。
- 私有作品、真实上传校验、任务/批次、进度、取消、候选采用、旧版本保护、下载和素材恢复。
- CPU 章节粗剪、明确音轨、生成视频配套 FLAC、剪辑选段、手动中文字幕、SRT/CSV/JSON 和素材备份。
- 持久任务队列、执行槽、费用预留、幂等与故障恢复；多 GPU 和扩缩容控制已有代码及模拟验收。
- Docker、PostgreSQL、同源代理、CI、受控发布和回滚；这些部署准备不等于已经买了服务器或改了域名。

LLM 编剧、人物图生成、音乐/TTS、Marble 世界模型尚未接入。H3受控执行与扩容已有代码及历史或模拟证据，但当前GPU关闭，新的真实推理池和供应商路由仍需分别验收。Hippius有实验适配，其当前条件写入差异阻止它直接成为主素材库；生产远端存储首选候选R2，当前预览实际使用Local。
